# Temperature Converter

## Task 3 – Temperature Converter

A clean and responsive temperature conversion web application created as part of the Oasis Infobyte Web Development & Designing Internship.

The application allows users to enter a temperature and convert it between Celsius, Fahrenheit, and Kelvin.

## Features

- Temperature input field
- Celsius, Fahrenheit and Kelvin unit selection
- Conversion of the entered value into all three units
- Input validation
- Absolute-zero validation
- Clear error messages
- Responsive design for desktop and mobile
- Clean and centered user interface

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Conversion Support

### Celsius
- Celsius → Fahrenheit
- Celsius → Kelvin

### Fahrenheit
- Fahrenheit → Celsius
- Fahrenheit → Kelvin

### Kelvin
- Kelvin → Celsius
- Kelvin → Fahrenheit

## Validation

The application handles:

- Empty input
- Invalid/non-numeric input
- Temperatures below absolute zero
