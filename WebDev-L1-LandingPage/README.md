# AgroSmart – Smart Farming Solutions

## Task 1 – Landing Page

A modern and responsive landing page designed for **AgroSmart**, a smart farming solutions concept. The page focuses on helping farmers discover modern farming solutions through a clean, simple and attractive interface.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- CSS Flexbox
- CSS Grid
- Responsive Web Design

## Features

- Sticky navigation bar
- Hero section with headline and call-to-action buttons
- Smart farming themed visual illustration
- Farming solutions/features section
- About section
- Contact/Get Started call-to-action
- Responsive design for desktop, tablet and mobile screens
- Clean green farming-themed color palette
- No JavaScript required

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. For the best development experience, use the VS Code Live Server extension.
